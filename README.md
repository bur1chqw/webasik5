# Assignment 5 — JavaScript Basics

Student: Burkhan Tokmagambet  
Group: SE-2525

This website contains nine separate JavaScript tasks (0–8), including DOM manipulation, mouse and keyboard events, a calculator, and an interactive To-Do list. The To-Do app stores tasks temporarily in a JavaScript array.

## How to run
Open `index.html` in a browser and use the navigation links to visit each task. Open the browser console with F12 to inspect Tasks 0 and 1.

## Publish
Upload all files to a GitHub repository. In Settings → Pages, deploy from the `main` branch, root folder.
